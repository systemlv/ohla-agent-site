# OhLa Agent Tools Directory

This project is a curated list of AI developer tools, MCP servers, agent frameworks, and workflow/templating resources.

## How to add a tool

1. Edit `data/tools.json`
2. Add a new object with:
   - `id`
   - `title`
   - `category`
   - `short_desc`
   - `url`
   - `official_site`
   - `repo`
   - `tags`
   - `type`
   - `status`
3. Submit a PR for review.

## Recommended categories

- Agent Frameworks
- MCP Servers
- MCP Collections
- Agent Skills
- Agent Plugins
- Agent Orchestration
- Agent Workspaces
- AI Apps
- RAG / Knowledge
- Workflow Templates
- Case Studies
- Platforms

These are curated resources, not a hosted runtime. The goal is to help developers discover and evaluate tools quickly.
